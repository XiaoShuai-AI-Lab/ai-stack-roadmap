# Key Takeaways

这一期最重要的不是记住三个名词，而是看懂它们背后的工程边界变化。

## 1. 三代 Ops 管的对象越来越宽

```text
MLOps
  -> 模型生产链路

LLMOps
  -> 大模型应用运行闭环

GenAIOps
  -> 生成式系统生产和治理链路
```

## 2. 用同一条链路比较更容易理解

```text
输入 -> 处理 -> 输出 -> 反馈 -> 闭环
```

同一个企业智能对话产品，在三代技术里都会经历这条链路，但每一环的变量都变多了。

## 3. 大模型时代的关键变化是变量变多

传统 ML 的输入输出更结构化。

大模型应用引入了：

- prompt；
- context；
- RAG；
- tools；
- cache；
- trace；
- safety evaluation。

所以工程化目标也从“把模型上线”扩展为“把应用行为纳入可观测、可评估、可回放的闭环”。

## 4. GenAIOps 继续扩大边界

生成式 AI 不只生成文字，还可能生成图像、音频、视频和多模态内容。

这意味着系统要额外管理：

- 生成质量；
- 内容安全；
- 多模态一致性；
- 人审流程；
- 策略治理；
- 证据链。

## 5. 最终目标不是完全确定，而是可治理

生成式系统天然有概率性。工程化不是让它变成传统软件，而是让它：

```text
可评估
可追踪
可回放
可治理
可持续改进
```
